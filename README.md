# 💛Pausa - Atividade Setembro amarelo

Pausa é um projeto web voltado ao acolhimento emocional e à promoção de cuidado pessoal em momentos de ansiedade, cansaço,
confusão ou tristeza. A ideia central é oferecer uma experiência simples e acolhedora, com exercícios de respiração,
frases reflexivas e informações sobre locais de apoio, como o CVV, CAPS e UBS.

A página foi desenvolvida para lembrar que nem todo dia precisa ser resolvido hoje e que buscar ajuda é uma forma de cuidado,
não de fraqueza. O projeto combina design leve, linguagem acessível e uma proposta de atenção emocional para pessoas que precisam de um momento de pausa e acolhimento.
